Proyecto: Modernización Banco NeoNexus

Resumen: Este proyecto presenta la propuesta de arquitectura empresarial para un banco pequeño que busca escalar sus servicios digitales manteniendo una infraestructura ágil. Se utiliza el marco TOGAF 9.2 para garantizar la alineación entre negocio y tecnología.

Objetivos del Sistema

  • Optimización de transacciones core mediante microservicios.
  • Garantía de trazabilidad de datos según normativas bancarias.
  • Mejora de la experiencia de usuario (UX) mediante interfaces limpias.

Análisis Descriptivo (TOGAF ADM)

Aplicación de las fases del ciclo ADM para el banco.

Fase B: Arquitectura de Negocio

Se identificaron los servicios esenciales de ahorro y crédito, eliminando redundancias en la atención al cliente.

Fase C: Arquitectura de Sistemas de Información

Trazabilidad: Cada transacción iniciada en la web se vincula directamente con un ID de auditoría en el backend.

Fase D: Arquitectura Tecnológica

Migración hacia una infraestructura híbrida para mayor resiliencia.

Conclusiones

La implementación de un diseño basado en Arquitectura Empresarial permite al banco no solo organizar su tecnología actual, sino prepararse para un crecimiento modular.
