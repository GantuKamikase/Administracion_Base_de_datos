Banco Digital

Resumen del Proyecto

Este proyecto presenta el diseño de arquitectura empresarial para un banco digital, integrando negocio y tecnología mediante TOGAF y ArchiMate.

Objetivo: Mejorar la apertura de cuentas digitales reduciendo el tiempo en 30%.

Diagrama ArchiMate

Modelo Simplificado

Explicación:

  • Business Layer: Cliente, Apertura de cuenta
  • Application Layer: Sistema bancario
  • Technology Layer: Servidores y base de datos

El diagrama muestra cómo el negocio se conecta con aplicaciones y tecnología.

Mapa de Arquitectura de TI

Capas:

  • Presentación: Web/App
  • Aplicación: Backend bancario
  • Datos: Base de datos
  • Infraestructura: Servidores

Análisis (TOGAF ADM)

Fases TOGAF

  • Arquitectura de Negocio: Procesos de apertura de cuenta
  • Arquitectura de Aplicación: Sistema bancario digital
  • Arquitectura Tecnológica: Infraestructura TI

Trazabilidad

Objetivo → Proceso → Sistema → Infraestructura

Conclusiones

  • La arquitectura empresarial alinea negocio y tecnología.
  • TOGAF permite estructurar la solución.
  • ArchiMate facilita la visualización.
